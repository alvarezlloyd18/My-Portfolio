Jhon LLoyd Portfolio - GitHub Pages
Files:
  index.html
  assets/portrait.webp   (hero photo, transparent background)
  assets/mediserve.jpg   (MediServe thumbnail)
  assets/resume.pdf      (resume download)
Replace any file in assets/ with the same name to update it.
Deploy: upload everything to a GitHub repo, then Settings > Pages > main / root.
GitHub buttons: set  const GITHUB='';  in index.html to your profile URL.
Open via GitHub Pages or a local server; needs internet for Tailwind and Google Fonts.
